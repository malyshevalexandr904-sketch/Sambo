# CHANGELOG

## 0.3.1 — доработки по демонстрации Phase 3 (2026-09-26)

### Изменено

- Текст согласия показывается оформленным (заголовки, абзацы, списки, выделение), без HTML: разметка превращается в элементы интерфейса.
- Импорт: строка с ошибкой показывает фамилию, имя и дату рождения так, как они записаны в файле (`source` в отчёте строки) — её легко найти и исправить.
- Карточка чужого или несуществующего спортсмена — понятное сообщение «Спортсмен не найден» со ссылкой к списку вместо «Не найдено».
- После добавления представителя — сообщение, что приглашение отправлено на указанный email.
- Отклонённый документ подписан «Отклонён …» вместо «Проверен …».
- Фильтры списка спортсменов и поля импорта и судей не обрезают подписи на экране ноутбука.

## 0.3.0 — Phase 3: Athletes (2026-09-25)

### Добавлено

- **Спортсмены:** человек и профили спортсмена, тренера, судьи; клуб и тренер периодами (переход между клубами закрывает прежний основной клуб), история разрядов ЕВСК с отменой, судейские категории. Список по видимости: тренер видит своих спортсменов, клуб — спортсменов клуба; чужой клуб — `404`.
- **Дубли:** поиск похожих при создании (та же дата рождения и похожее ФИО или то же ФИО и близкая дата), кандидаты показываются в публичном виде; создать всё равно — с причиной в аудите. Слияние дублей администратором платформы.
- **Импорт из CSV/XLSX:** загрузка файла, разбор в worker, предпросмотр с ошибками по полям и дублями, выбор действия по строке (создать, пропустить, привязать), отчёт. Заголовки по-русски, до 1000 строк, `Idempotency-Key`.
- **Законные представители:** добавление, подтверждение тренером или клубом, приглашение по email и привязка аккаунта, кабинет «Мои спортсмены».
- **Согласия (ФЗ-152):** обработка ПДн, публикация, данные о здоровье; тексты с версиями, опубликованный текст неизменен; электронно — только подтверждённый представитель или совершеннолетний спортсмен, бумажное — сканом через клуб; отзыв с событием `consent.revoked`.
- **Документы:** загрузка в приватное хранилище, статусы `UPLOADED → UNDER_REVIEW → VERIFIED / REJECTED`, `EXPIRED` фоновой задачей, письмо об отклонении, журнал доступа при просмотре и скачивании. Проверка — секретарём турнира.
- **Правила и категории:** наборы правил с версиями (параметры по схеме `RuleSetParametersV1`, публикация с контрольной суммой, опубликованная версия неизменна), возрастные группы и весовые категории, шаблоны наборов категорий; `calculateAge` (три политики) и `resolveEligibleCategories`.
- **Web:** кабинеты тренера и клуба (спортсмены, карточка, импорт, тренеры), представителя (дети, согласия), секретаря (проверка документов); админ-разделы судей, категорий, правил, текстов согласий; «Мои данные» в профиле.
- Seed: 20 спортсменов 2011–2014 г. р., тренеры, судьи, представитель с аккаунтом, секретарь учебного турнира, тексты согласий, набор правил, категории.

### Изменено

- Ответы API по умолчанию `Cache-Control: no-store`; `If-None-Match` с токеном версии (`"v{n}"`) не даёт `304`: ETag версии — для `If-Match`, а не для кэша. Раньше браузер мог показывать устаревшую карточку после изменения производных полей.
- Права проверяются по нескольким областям ресурса (спортсмен в клубе и спортшколе); списки фильтруются по охвату права в SQL.

## 0.2.1 — доработки по демонстрации Phase 2 (2026-09-24)

### Изменено

- **Создатель организации с полномочиями не входит в её состав.** Администратор платформы или вышестоящая федерация, создающие организацию, регистрируют её от имени руководителя: иначе создатель получал права роли руководителя (спортсмены, документы, заявки), которых нет в его собственной роли. Первый руководитель приглашается полем `managerEmail`. Самостоятельная регистрация — как раньше: организация на проверке, создатель — руководитель.
- Карточка организации показывает вышестоящую организацию, страну, регион и адрес; в ответе `GET /organizations/{id}` — поле `parent`.
- Системные настройки «Email поддержки» и «Баннер о технических работах» редактируются обычными полями вместо JSON.
- Активные сеансы показывают браузер и систему («Chrome 141 · Linux») вместо строки User-Agent.
- Письма на русском: кавычки внутри «ёлочек» — „лапки“ («Спортивный клуб „Буревестник“»).

- Web: вход, регистрация, подтверждение email, восстановление пароля, приглашения; админ-панель (обзор, пользователи, организации, журнал аудита, настройки), профиль (сеансы, TOTP); ru и en; CSP с nonce.
- Docker-образы, `docker-compose.yml`, CI (lint, typecheck, unit, integration, build, gitleaks, audit, Docker).
