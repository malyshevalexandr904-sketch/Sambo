## Что ещё не заполнено

В Политике обработки персональных данных остались поля в квадратных скобках:

- номер оператора в реестре Роскомнадзора (п. 1.4);
- город, где расположены серверы (п. 6.2);
- наименование и адрес хостинг-провайдера (согласие, п. 4; Политика, п. 6.3).

Перед публикацией на сайте документы стоит показать юристу.
